- **Facts for nine more checklists**: eight new pre-steps hand the model facts, placed after the steps in the prompt. Changelog and changeset gets the changed packages and the changesets that name them. Docs gets the docs files changed and the READMEs above changed code that stayed the same. Tests gets each changed source file with its changed test, an existing one, or none. File and folder structure gets each new file's folder, suffix and name case. Does what it says gets the lines changed by area and kind of file. Personal data and logs, and Logs and metrics, get the log, metric, analytics and error-report calls the diff adds. Feature flags gets the flags read and dropped and where the repo still names them. Type safety gets the type escapes added and the repo's settings for them. The scripts read only the diff and the checkout's files, and never run the repo's code.
