- **Slash commands**: a comment can start Axon Shaft with `/review`, `/fix`, `/ask` or `/help` at the start of a line, besides `@axonshaft review`. `/review` reviews the pull request now, `/help` posts the list of commands, and `/fix` and `/ask` end with a notice until Task and Reply are built. Commands in quotes or code don't count
- **Workflow trigger**: the workflow's `if:` also starts on a comment with one of the commands; copy the new one from the README or the dashboard
