- **Advisory links**: a Known vulnerabilities finding links each advisory ID to its page, GitHub's advisory page for a `GHSA-` ID or the record on osv.dev for any other. The finding's row in the summary and on its check run links to its most severe advisory, and the check run's details link goes there too. The run report sends the link to the Axon Shaft API with the finding.
